I updated the tests in `tests/test_make.py` for the new instance support in `attrs.fields()`. The full suite passes: 1380 passed, 8 skipped, 1 xfailed. I did not touch production code or commit anything.

The old `TestFields.test_instance` asserted that passing an instance raises `TypeError("Passed object must be a class.")`. That is the opposite of the new behaviour, so I rewrote it.

What the tests now cover:
- **Instances of attrs classes:** `test_instance` (rewritten, using hypothesis) checks `fields(C()) is fields(C)`.
- **Slotted, dict-based and subclassed classes:** `test_instance_values` also checks that `attrs.fields` accepts instances.
- **Generic classes:** `test_instance_generic` covers instances of plain and aliased generic classes.
- **Non-attrs instances:** `test_instance_non_attrs` checks that `1`, `"s"`, `None`, a list, `object()` and a plain class instance raise `TypeError` with the new message.
- **`__attrs_attrs__ = None`:** `test_instance_attrs_attrs_none` checks that an instance of a class setting this to `None` is rejected.
